# خِدمتي — واجهة الويب

واجهة عربية RTL ومتجاوبة مع شاشات الكمبيوتر والموبايل، مبنية بـ React وVite.

## التشغيل المحلي

1. شغّل MongoDB والخادم الخلفي من مجلد المشروع الرئيسي باستخدام `npm start`.
2. شغّل الواجهة من هذا المجلد باستخدام `npm run dev`.
3. افتح الرابط الذي يعرضه Vite، غالبًا `http://localhost:5173`.

تمرر الواجهة طلبات `/api` إلى الخادم الخلفي على `http://localhost:5000`.
لتجربة الواجهة على الموبايل، افتح عنوان الشبكة المحلية الذي يعرضه Vite على الهاتف
المتصل بشبكة Wi-Fi نفسها. يجب السماح باتصالات Node.js عبر جدار حماية الجهاز.

يمكن تغيير عنوان API باستخدام `VITE_API_URL` عند بناء الواجهة أو تشغيلها.

وضع OTP التجريبي الموثق في ملف README الرئيسي مخصص للتطوير المحلي فقط.
